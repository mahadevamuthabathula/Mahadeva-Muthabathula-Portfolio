# Mahadeva-Muthabathula-Portfolio

## Project structure

- HTML pages and site configuration stay at the project root.
- `css/` contains the site stylesheet.
- `js/` contains the shared browser script.
- `assets/` groups `documents/`, `fonts/`, `icons/`, `images/`, and `logos/`.

Run `npm run dev` for local development or `npm run build` to create the static site in `dist/`.
